## ✨ What is NATA?

**NATA (Neural AI Task Assistant)** is a browser-based AI productivity assistant that automates the most repetitive tasks professionals face every day. Built with a clean, intuitive interface and powered by **Lovable**, NATA brings five specialised AI tools into one seamless experience — no technical skills required.

## 🧠 How Prompt Engineering Powers NATA

Each feature in NATA uses a **purpose-built system prompt** — not a generic chatbot instruction. Every prompt includes:

1. **Role Definition** — tells the model exactly who it is (e.g. a professional email writer, a productivity coach)
2. **Output Structure** — specifies the exact format of the response
3. **Constraints** — prevents hallucination and keeps responses on-task
4. **Dynamic Injection** — user inputs (tone, audience, timeframe) are injected at runtime for precision

This approach ensures consistent, structured, professional outputs — every single time.

## 🛡️ Responsible AI

NATA was built with ethics in mind from day one:

- 🔒 **No data storage** — user inputs are never logged or stored
- ⚠️ **Accuracy disclaimers** — Research Assistant reminds users to verify AI-generated content
- ⚖️ **Bias-aware prompts** — avoids assumptions about gender, nationality, or seniority
- 👤 **Human-in-the-loop** — NATA assists, humans decide
